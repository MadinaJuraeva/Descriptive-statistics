# Doing math and collaborating

In this repository we will work through looking at a file in github, creating a branch, performing descriptive statisics, creating a pull request

## Objective
As a Data Analyst it is necessary to understand statisics and collaborate with team members

## Task 

This work can be done on github in the browser. The calculations can be done externally if required.

Please work in pairs.
1. Create a  branch for your pair.
2. From this branch, each person should create an additional branch for themselves.
3. Each person should edit the [Questions.md](Questions.md) and enter the answers. The data for these questions can be found in the [Observations.txt](Observations.txt) file.
4. Each person should write additional questions about the descriptive statistics at the bottom of the questions.md file and commit the changes as necessary.
5. Create a pull request to merge the work back to the pair branch (not main!) 
6. Review the pull requests and deal with any conflicts before merging. This [guide](https://docs.github.com/en/github/collaborating-with-issues-and-pull-requests/resolving-a-merge-conflict-on-github) might help you.

Keep in mind, you succeed better as a team. There are NO stupid questions! If you already feel comfortable with the concepts, you might even learn more from teaching them!

### Extra Credit
